              手机在任何网络(流量 / 别人家 WiFi)与电脑点对点直连,数据不经第三方:

              应答码会经公共 MQTT 云端自动回传,无需电脑摄像头、无需复制粘贴。
            

            

            

              
              
              
            

            
            

              
🌐 一键临时隧道(免注册,首次准备推荐)

              

                电脑用系统自带 ssh 连免费隧道服务,手机扫下方二维码即可在任何网络打开连接页 ——
                页面自动完成 P2P 握手(信令走隧道、数据走直连),并可将连接文件保存到手机,以后无需隧道。
              

              

                
                
                
              

              

              

                

                  

                  

                    
手机(任意网络)扫码 → 打开「远程直连」连接页:

                    

                  

                

              

            

            

              

                

                

                  
手机端操作(只扫一次):

                  
1. 手机打开「漫画+小说」阅读页(首次需在同一网络下打开 /mobile 并「保存本页」)

                  
2. 点「📶 远程直连」→「📷 扫电脑屏幕」对准左侧二维码

                  
3. 等待自动握手,直连成功后状态变「● 直连」

                  

                

              

            

            

            

              兜底方式:手动粘贴应答码 / 事件日志
              

                云端回传不可用时(如防火墙拦了 MQTT),手机端会显示应答码 —— 复制粘贴到下面提交,或用「摄像头扫码」。
              

              
              
              

            

            

              高级:TURN 中继(打洞总失败时配置,可留空)
              

                校园网多为对称 NAT,STUN 打洞可能失败;配置 TURN 服务器后走中继兜底。
                可用 metered.ca 免费节点,如 openrelay.metered.ca:443?transport=tcp(用户名 openrelayproject / 密码 openrelayproject)。
              

              

                

                

                

              

              
随下方「保存设置」一起保存,生成新连接码后生效。
