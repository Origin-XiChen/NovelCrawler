# 漫画+小说

一个带**模糊搜索**、**多源聚合**、**防封禁**策略的小说/漫画下载工具（多源小说爬虫 GUI 版）。

> ⚠️ **法律与版权声明（学习版）**
> 本项目为**学习版**工具，仅供个人学习、技术研究与编程实践，**严禁用于商业用途**。
> **资源来源于网络**：所有书籍/漫画均来自第三方站点，本程序**只是按你的指令调用、请求并下载**，不内置、不存储、不传播任何资源。
> 多数在线小说受版权保护，请勿使用本工具批量下载并传播受版权保护的书籍。
> 建议仅下载已进入公有领域（如《西游记》《三国演义》等古典名著）或作者明确授权的作品，并在下载后 24 小时内删除。
> 使用本工具造成的一切后果由使用者自行承担。本项目基于 **GPL-3.0** 开源，见 [LICENSE](LICENSE)。

## 功能特性

| 特性 | 说明 |
|------|------|
| 🔍 **模糊搜索** | 输入 `harry potter` 自动映射到中文《哈利波特》；支持拼音(如 `ha li bo te`)；内置 60+ 作品中外名映射表，可自行扩充 |
| 🌐 **多源搜索** | 内置 10 个书源并发搜索、结果聚合去重；单源失败自动跳过；相关性过滤剔除无关推荐；限流自动等待重试 |
| 📚 **书架收藏** | 搜索时点 ☆ 收藏；书架一键"检查更新"(检测新章节并增量下载) |
| 📖 **在线阅读器** | 已下载 TXT 网页直接阅读:章节目录、上下章导航、字号调节、记忆进度 |
| 🔗 **URL 直连** | 填入任意书籍详情页/目录页 URL 即可下载(含未收录站点,自动通用源兜底) |
| 📕 **EPUB 导出** | TXT / EPUB 两种格式(EPUB 标准库生成,零依赖) |
| 🎨 **漫画聚合** | 多源漫画搜索/下载,打包 PDF(按话/合集/ZIP 三种模式);在线阅读、独立阅读器窗口、进度记忆 |
| 📄 **大 PDF 治理** | 生成端图片压缩(三档质量)、存量 PDF 一键压缩、按章节拆分大合集(pypdf 原样复制不损画质)、pdf.js 分段 Range 加载与图片直读双模式 |
| ⚡ **多线程下载** | 可选 1~5 线程并发抓取,千章书提速数倍 |
| 🛡️ **防封禁** | 随机 UA 池、请求随机间隔、指数退避重试、书源冷却控制、可选代理 |
| 📄 **章节下载** | 目录倒序/分页/去重自动处理；TXT 断点续传；可指定章节范围 |
| ⚙️ **可扩展** | GUI 设置面板管理书源(启用/停用/测试/添加) |
| 📦 **独立 exe** | 双击 `build_exe.bat`(命令行参数)或 `build_exe_spec.bat`(spec 配置)打包,两种方式等价 |

## 快速开始

### 0. 一键启动器(最简单)

**双击 `start.bat`** 即可:自动找 Python → 装依赖(仅首次)→ 选空闲端口 → 启动 GUI → 打开浏览器。

```bash
python start.py                # 命令行方式
python start.py --port 9000    # 指定端口
python start.py --no-browser   # 不自动打开浏览器
```

> 想放桌面:右键 `start.bat` → 发送到 → 桌面快捷方式。

### 0. 可视化 GUI(推荐)

```bash
python gui_server.py --open        # 自动打开浏览器
python gui_server.py --port 8899   # 指定端口
```

浏览器打开后即可:
- 🔍 顶部搜索框输入关键词(支持英文,如 `harry potter` → 《哈利波特》)
- 🎯 点击书源标签可筛选搜索范围(默认全部)
- 📋 点击左侧结果 → 右侧设置章节范围/间隔/目录 → 下载
- 📊 实时进度条 + 日志 + 已下载文件列表(可直接点"打开"查看)
- ⚙️ **设置栏目**(右上角),三个标签页:
  - **书源管理**:全部书源列表(内置+自定义),可启用/停用、**测试连接**(实抓首页/搜索/正文验证可用性)、删除自定义源
  - **添加书源**:填写名称/域名/编码/搜索接口/章节正则,添加自定义源
  - **全局设置**:代理、默认章节间隔、默认输出目录、SSL 校验开关

### 1. 交互模式(CLI)

```bash
python main.py
```

```
🔍 搜索书名(支持英文,如 harry potter)> harry potter
```

```bash

python main.py download "https://www.biquge365.net/book/76509/" --start 1 --end 20 --delay 0.5
```

### 4. 其他命令

```bash

```

## 命令行参数

| 参数 | 说明 | 默认 |
|------|------|------|
| `--start N` | 起始章节(1-based) | 1 |
| `--end N` | 结束章节 | 全部 |
| `--delay S` | 章节间延迟秒数(防封禁) | 1.2 |
| `--out DIR` | 输出目录 | downloads |
| `--proxy URL` | HTTP 代理,如 `http://127.0.0.1:7890` | 无 |
| `--workers N` | 搜索并发书源数 | 3 |

也支持环境变量 `NOVEL_PROXY` 设置代理。

## 书源仓库同步(推荐)

内置**书源订阅中心**(`novel/source_registry.py`),从社区维护的 GitHub 书源仓库自动挖掘可用站点:

- **GUI**:设置 → 书源管理 → **📚 快捷订阅**区:
  - 预置订阅:**tickmao/Novel**(1000+ 源)、**coolxy/legado**(阅读App书源)
  - 添加任意 GitHub 仓库(自动解析书源文件路径,支持直链/blob 链接)
  - 点订阅项 **[刷新]** → 拉取 → 探测可达性 → 验证目录/正文 → 展示候选(按正文可抓字数排序)→ 勾选导入
  - **[🔧 修正搜索接口]** 可对候选池二次修正搜索配置
- **CLI**:
  ```bash
  python -m novel.source_registry sync --limit 500   # 同步前500个
  python -m novel.source_registry sync               # 全量
  python -m novel.source_registry fix-search         # 二次修正候选搜索接口
  python -m novel.source_registry list               # 查看候选池
  ```
- 订阅列表保存在 `subscriptions.json`;候选池保存在 `source_candidates.json`,刷新自动跳过已内置域名;同名书源导入时自动加序号
- legado 的 JS/XPath 规则会转换为本工具的 JSON 规则;搜索接口 best-effort 转换(部分源仅直连可用,可用"测试连接"验证)

> 笔趣阁类站点域名频繁更换，失效时可在 GUI「设置 → 添加书源」中新增，或勾选启用后点「测试」确认可用性。

## 添加自定义书源

**推荐方式(GUI)**:设置 → 添加书源,填写表单即可;或设置 → 书源管理 → 📥 导入书源 JSON。

编辑项目根目录的 `config.json`，在 `sources` 数组中添加(或直接导入下方格式):

```json
{
  "name": "我的源",
  "base": "https://example.com",
  "charset": "gbk",
  "search": {
    "method": "POST",
    "path": "/s.php",
    "param": "s",
    "extra": { "type": "articlename" }
  },
  "search_interval": 15,
  "book_href_pattern": "/book/\\d+/",
  "chapter_href_pattern": "/chapter/\\d+/",
  "toc_reverse": false,
  "enabled": true
}
```

字段说明见 `novel/config.py` 头部注释。

## 书源分享(规则化)

每个书源可导出为**自包含的 JSON 规则**,复制粘贴即可传播;导入方在「设置 → 书源管理 → 📥 导入书源(JSON)」粘贴即可使用(支持单个对象或数组)。

```json
{
  "name": "示例源",
  "base": "https://example.com",
  "charset": "gbk",
  "verify_ssl": true,
  "search_interval": 15,
  "search": {
    "method": "POST", "path": "/s.php", "param": "s",
    "extra": { "type": "articlename" }
  },
  "book": { "href_pattern": "/book/\\d+/" },
  "toc": {
    "url_template": "/newbook/{bid}/",
    "chapter_pattern": "/chapter/\\d+/",
    "container": "全部章节",
    "reverse": true
  },
  "content": { "selector": "div#content" }
}
```

| 字段 | 说明 |
|------|------|
| `base` / `charset` / `verify_ssl` | 站点地址 / 编码 / 是否校验证书 |
| `search` | 搜索接口:method/path/param/extra;`null`=不支持搜索 |
| `book.href_pattern` | 搜索结果中书籍详情页链接正则 |
| `toc.url_template` | 目录页地址模板,`{bid}` 自动替换为书籍ID;留空则自动推断 |
| `toc.chapter_pattern` | 章节链接正则 |
| `toc.container` | 目录容器标题关键词(多个用 `/` 分隔);留空自动识别"全部章节" |
| `toc.reverse` | 目录是否倒序需反转 |
| `content.selector` | 正文容器 CSS 选择器;留空自动探测 |

项目自带示例规则包 `shareable_sources.json`(内置可用源的导出),GUI 里可直接导入。

## 手机远程连接(校园网 / 外出也能用)

设置页「手机」分类提供四种连接方式(分页签),按可靠性排列:

| 方式 | 原理 | 适用场景 | 依赖 |
|------|------|----------|------|
| **局域网** | 手机与电脑同一网络,扫码直连 `http://PC-IP:端口/mobile` | 家里 / 宿舍路由器 / 公司 WiFi | 无 |
| **热点接力** | 电脑开 Windows 移动热点,手机连热点后与电脑同处 `192.168.137.x` 网段,绕过校园网隔离 | **校园网首选** | 无线网卡 |
| **公网穿透** | 电脑主动出站连隧道服务(natapp / cpolar / frp),手机访问公网域名经中转到达电脑;设置页可直接启动/停止并展示公网二维码 | 校园网 / 出门在外 | 第三方隧道客户端(免费) |
| **任意网络直连** | WebRTC 点对点直连;**手机只扫一次码**,应答码经公共 MQTT 云端自动回传 | 手机用流量 / 任何陌生网络也直连 | `pip install aiortc opencv-python-headless`(扫码兜底才需摄像头) |

**为什么校园网下局域网会失效**:高校 WiFi 普遍开启 AP 隔离(同网段设备禁止互访)且认证网关只放行出站连接,手机无法直连电脑 IP。此时请用「热点接力」或「公网穿透」;「任意网络直连」适合手机只有流量的场景。

### 任意网络直连(一键扫码 + 复合流程)

「远程直连」现在是一个**独立连接页**(`/direct`,即"连接文件"),配合**一键临时隧道**形成完整的跨网络复合流程:

```
电脑:设置 → 手机 → 任意网络直连 → 「⚡ 一键开启临时隧道」(免注册,系统自带 ssh)
        ↓ 公网二维码
手机(任意网络)扫码 → 打开 /direct 连接页(首次准备:页面经隧道传到手机)
        ↓ 自动(零操作)
连接页自动完成 P2P 握手:信令走隧道 HTTP,数据面由 ICE 尝试点对点直连
        ↓
✅ P2P 打通 → 数据直连,隧道可停(「保存本连接文件」后下次不再需要隧道)
   未打通 → 自动保持隧道中转,功能完整不受损
```

- **连接页两种用法**:① 经隧道/局域网 http 打开 → 自动握手;② 作为本地文件打开(电脑端「📥 下载连接文件」后微信/QQ 发给手机)→ 扫一次连接码 + 云端自动回传。连接成功后「📖 载入完整阅读页」会把完整手机页经直连通道内嵌打开(所有 API 经 postMessage 由同一条 DataChannel 转发)。
- **一键临时隧道**:依次尝试 pinggy.io / serveo.net / localhost.run(免注册 ssh 服务,部分网络/时期可能不可用;校园网常拦出站 22 端口)。全部失败时会给出替代方案(连接文件 / natapp / cpolar)。
- **研究结论**:SSH 隧道是中继,不能代替打洞;它的价值是**信令通道 + 首次页面传递**,真正的数据面仍由 WebRTC ICE 尝试直连,失败自动回落隧道 —— 任何网络下都可用,直连只是提速。

**一键扫码直连(不用隧道,需先保存过页面)**:电脑「生成连接码」→ 手机在阅读页/连接页「📷 扫电脑屏幕」→ 应答码经公共 MQTT 云端(broker-cn.emqx.io 等 3 节点)自动回传 → 直连。主题由连接码派生(SHA-256 截断),中继只见密文式 SDP。

**兜底链**:云端回传失败 → 电脑「摄像头扫码」→ 手动粘贴应答码;P2P 打洞失败(对称 NAT)→ 设置「高级:TURN 中继」或保持隧道。首次获取页面只能靠:同一网络扫码 / 临时隧道 / 连接文件传输,三者必居其一(网络隔离的物理限制)。

### 📦 离线手机包(电脑端打包)

设置 → 手机 → **📦 离线手机包**:勾选已下载的小说 / 漫画 → 打包为离线文件(ZIP 进度可视 / HTML 单文件)→
微信 / QQ / 邮件发给手机即可离线阅读,产物与手机端「打包快照」完全一致(HTML 直接打开;ZIP 解压后打开 index.html)。

**排障要点**:
- **设置页会显示中继状态**(`云端自动回传: x/3 已连接`),0/3 说明电脑出站被防火墙拦截,检查系统防火墙或换网络。
- **摄像头不可用 / 被占用**:手机端点「复制应答码」发给电脑,在「兜底方式 → 手动粘贴应答码」里提交即可。
- **打洞总失败**(对称 NAT):展开「高级:TURN 中继」填入免费 TURN(如 metered.ca openrelay),重新生成连接码后手机端自动带上 TURN 配置。
- **扫不出来**:连接码约 1KB,二维码必须按原始尺寸显示(电脑端 336px、手机端铺满屏宽);屏幕亮度调高、保持 20–30cm 距离。
- **公网穿透拿不到地址**:frpc 不会在日志里打印公网地址(写在自己的配置文件里),只有 natapp / cpolar / ngrok 这类会打印的客户端才能自动识别。

## 独立阅读器窗口

PC 端点「阅读」(小说/漫画/EPUB 在线/已下载 PDF)默认打开**独立阅读器窗口**:

- 阅读器页面 `reader.html` 亦可直接访问:`/reader.html?mode=comic&source=...&comic_id=...`
  (mode 支持 novel / novel_online / epub / comic / pdf)
- 内嵌阅读器仍保留作为回退(独立窗口被拦截时自动落回)

阅读器 UI:漫画图片级缩放(A±/Ctrl+滚轮只缩放图片,工具条恒定)、滚动页码 HUD
(第 X / N 页)、单页加载失败自动重试与「点击重试」占位、PDF 目录右上抽屉、

## 常见问题

- **搜索提示 404 / 连接失败**：该源可能已失效或限流，工具会自动尝试其他源；也可在「设置 → 添加书源」新增镜像。
- **搜索总是搜不到 / 结果与关键词无关**：已内置两道防线——① 相关性过滤：只保留书名命中关键词的结果，过滤"无视关键词返回推荐"的假搜索源；② 限流自动重试：站点提示"搜索间隔15秒"时自动等待后重试。若某个源被限流，搜索结果会变慢(20~60秒)但最终仍会返回正确结果。
- **搜索较慢**：笔趣阁系站点普遍有 15 秒搜索间隔限制，连续高频搜索会触发自动等待，属正常现象；低频使用(隔几分钟搜一次)通常 3~10 秒出结果。
- **下载中断后重跑**：自动断点续传，只补未下载章节。
- **某些书源正文为 JS 加载**：解析器会自动跳过并尝试其他候选目录页/源。
- **下载速度慢**：是防封禁限速所致，可调小 `--delay`(不建议低于 0.5)。
